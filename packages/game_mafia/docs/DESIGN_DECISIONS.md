# Mafia 구조 결정

## 서버와 클라이언트 책임

- 역할 배정, 행동 검증, 사망, 투표, 승패 판정은 서버가 결정합니다.
- controller는 서버 snapshot을 화면 상태로 옮기고 명령 결과를 반영합니다.
- board와 animation은 화면 연출만 담당하며 게임 규칙을 진행시키지 않습니다.

## 기기 책임

- 휴대폰은 개인 역할, 개인 행동, 투표와 관전 정보를 표시합니다.
- 태블릿은 전체 진행, 공용 발표, 개표, 처형과 결과를 표시합니다.
- 개인 역할 정보는 태블릿 구독에 포함하지 않습니다.

## 상태 소유권

- 한 게임 세션의 RTDB 구독 소유자는 `shared/providers/game_controller.dart` 하나입니다.
- Map 파싱은 `shared/services/public_state_mapper.dart`와
  `private_state_mapper.dart`에 둡니다.
- 기기별 `board_state.dart`는 화면 타이머와 연출 lifecycle만 소유합니다.

과거 화면 단위 결정과 Figma 조사 내용은 [HISTORY.md](HISTORY.md)를 참고하세요.


## 선택 가능한 규칙 (2026-10-04)

- 기본/확장/자유 프리셋을 제공한다. 확장은 기존 인원별 추천표를 유지하며 기본값이다.
  기본은 시민·마피아·경찰·의사만 쓴다. 자유는 현재 구성에서 직접 편집한다.
- 설정 화면은 진영별 인원과 불균형·다중 정보 역할 경고를 표시한다. 단순 권장은
  시작을 막지 않는다. 마피아 부재·인원 불일치·초기 마피아 승리 구성이면 서버도 거부한다.
  연쇄살인마/교단이 있으면 기존 승리 판정에 맞춰 마피아 수만으로 거부하지 않는다.
- 밤 행동은 한 번 확정한다. 같은 commandId 재시도는 멱등 응답이며 새 commandId로
  다시 제출해도 대상을 바꾸지 못한다. 모든 행동이 확정된 wrapUp에서 실제 해결
  엔진의 복사본으로 차단·전향을 반영한 조사 결과만 private에 복사한다. 사망·전향·
  능력 사용 횟수·기자 공개는 원래 밤 해결 시점까지 변경하지 않는다.
- 밤 효과음, 세 행동 구간의 시간과 마무리 시간은 이번 변경 범위에서 제외했다.
- `public.rules`의 기본값은 `{trial: false, executionReveal: "role"}`이다.
  옵션 누락 게임은 기존 직접 처형·직업 공개를 유지한다. 다시하기는 직전 규칙을 유지한다.
- `trial: true`면 지목 투표의 단독 최다 득표자가 30초 변론하고 30초 찬반 투표를 한다.
  `phase`는 `voting` 그대로이고 `public.trial = {stage, candidateUid}`로 구분한다.
  후보를 포함한 생존 투표권자가 각 1표를 내며 정치인 가중치는 지목 투표에만 적용한다.
  기권을 포함한 투표권자 수의 엄격한 과반수가 찬성해야 처형한다. 후보 이탈은 무처형,
  다른 이탈은 그 표를 제거하고 분모를 갱신한다. 지목 동률은 변론 없이 무처형이다.
- 찬반 선택은 `server.trialVotes`, 본인 선택은 `private/{uid}.trialVote`에 둔다.
  결과는 `public.voteResult.verdict`에 찬성/반대 합계만 기록한다. 기존 callable 이름과
  deadline 처리 경로를 재사용한다. 구버전 클라이언트는 새 옵션 UI를 이해하지 못하므로
  새 옵션을 쓰는 방은 휴대폰·태블릿 모두 업데이트된 클라이언트로 진행해야 한다.
- 처형 공개는 `role`(정확한 직업), `faction`(진영), `hidden`(미공개)이다. 서버가
  정확한 직업을 공개 데이터에 쓸지 결정한다. 기존 기자 공개는 유지하며 게임 종료 시
  전원의 역할을 공개한다. `public.composition`은 최초 역할별 인원수만 담고 배정 uid는 없다.
- 사망자 관전 정보는 private로만 전달하고 화면은 누르는 동안만 보인다. 손을 떼거나
  터치 취소·앱 비활성화 시 숨기며 숨긴 역할 목록은 semantics에서도 제거한다.
- 규칙 창은 이번 판 옵션과 선택 역할의 실제 능력·중립 승리 조건을 설명한다.
  의사 자가 보호, 기자 무제한 취재, 마피아 동률 무작위 등 기존 능력 규칙은 유지한다.

`test/tablet/role_setup_rules_test.dart`와 `test/shared/widgets/rules_ui_test.dart`를 참고한다.
