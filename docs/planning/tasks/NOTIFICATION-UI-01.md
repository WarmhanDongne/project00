현재 분류·상태·다음 행동은 작업 목록을 기준으로 확인한다. 아래 날짜가 붙은 상태·결정은 당시 기록이다.

**사용자 알림 디자인 통일**

- 사용자 요청: 방 강퇴, 게임에서 나가 로비로 복귀하는 경우, 게임 내 사용자 알림 등의
  디자인을 통일한다. 대상과 현재 표시 방식은 조사 전이다.
- 완료 조건: 대상 알림의 표시 형태·문구 톤·우선순위를 정하고 적용·확인한다. 네트워크
  경고 등 필요한 안내를 없애지 않는다. winner 아래 안내 겹침은 기존 별도 작업과 연결한다.
