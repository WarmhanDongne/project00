# WINNER-CONNECTION-LAYER-01

winner 아래 연결 안내 겹침

[작업 목록으로 돌아가기](../TASKS.md) · [관리 방법](../TASK_MANAGEMENT.md)

현재 분류·상태·다음 행동은 작업 목록을 기준으로 확인한다. 아래 날짜가 붙은 상태·결정은 당시 기록이다.

- 담당 Issue: 착수 승인 시 생성.
- 분류 결정 근거: 사용자가 오류가 아닌 추후 개선으로 지정하고 통과 확정.

## 사용자 근거와 범위

위와 같은 APK·게임·기기 조합에서 winner 표시 직후 태블릿 앱을 강제 종료하면,
winner 화면 아래에 사용자가 표현한 `태블릿 오류 화면`이 나타났다. 정확한 화면 문구,
해당 휴대폰과 route는 미제공이며 특정 widget의 문제라고 단정하지 않는다.
재시작 후 대기실 복귀·winner 닫힘·다음 게임 선택을 포함한 시나리오 3은 통과했다.
기존 검정 화면/복귀 실패인 FINISH-SYNC-01을 재개방하지 않는다.

## 착수 조건과 조사 계획

- finished/winner 표시 중 controller 연결 안내가 뒤에 함께 나타나는 순서를 재현한다.
- 종료 결과 화면과 재연결 안내의 표시 우선순위를 조사하고 불필요한 중복 안내를 줄인다.
- 게임 진행 중 필요한 네트워크 안내, 그룹 나가기, 태블릿 복원·대기실 복귀를 보존한다.

## 완료 기준

- winner와 controller 연결 안내가 혼란스럽게 겹치지 않는다.
- 태블릿 강제 종료·재시작 뒤 winner 닫힘과 전체 휴대폰 복귀 회귀가 없다.
- 관련 widget 테스트와 같은 시나리오의 기기 확인을 통과한다.
