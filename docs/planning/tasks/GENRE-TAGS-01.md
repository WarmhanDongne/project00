# GENRE-TAGS-01

태블릿 장르 태그 표시 범위 정리

[작업 목록으로 돌아가기](../TASKS.md) · [관리 방법](../TASK_MANAGEMENT.md)

현재 분류·상태·다음 행동은 작업 목록을 기준으로 확인한다. 아래 날짜가 붙은 상태·결정은 당시 기록이다.

**태블릿 장르 태그 표시 범위 정리**

- 사용자 표현: `장르 전체 뜨기`, `현재 보유 중인 게임 목록에 대해서만 장르 태그가
  태블릿 상단에 뜨는 것`.
- 미확정: 보유 게임의 장르만 표시하려는 것인지, 현재 그 상태여서 보유 여부와 관계없이
  전체 장르를 표시하려는 것인지 대화에서 명확히 선택되지 않았다. 구현 전 확인한다.
- 완료 조건: 표시 범위와 필터 동작을 확정하고 보유 목록·선택 장르에 따른 결과를 확인한다.
