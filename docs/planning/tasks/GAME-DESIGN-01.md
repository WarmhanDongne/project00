**게임 디자인 개선**

- 사용자 요청을 등록했다. 대상 게임과 휴대폰·태블릿 화면 범위, 공통 디자인 기준은 미정이다.
- 완료 조건 초안: 대상과 디자인 기준을 정하고 정보 가독성·핵심 조작을 확인한다.
  게임 규칙이나 상태 계약 변경을 디자인 작업으로 간주하지 않는다.
