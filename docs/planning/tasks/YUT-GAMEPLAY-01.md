# YUT-GAMEPLAY-01

윷놀이, 전략 윷놀이, 전략 윷놀이 에디션의 실제 게임 진행과 태블릿·휴대폰 화면.

## 확정 규칙

- 일반 윷놀이: 2~4인, 네 방향 자리 중 참가 인원 배치, 차례마다 현재 플레이어가 윷 4개를 던진다. 한 개의
  빨간 표시로 백도를 판정하며, 네 말 완주가 승리 조건이다.
- 전략 윷놀이: 4인 2팀, 좌우 진영. 매 차례 네 명 모두 각자 무표식 윷 한 개의 앞·뒤를
  휴대폰에서 비공개 선택하고 함께 공개한다. 도는 백도로 판정한다. 팀의 네 말 모두를
  먼저 완주시키면 승리한다.
- 전략 윷놀이 에디션은 별도 게임 ID·화면 테마를 쓰고 전략 윷놀이 서버 규칙을 공유한다.
- 일반 윷놀이는 잡기·업기·윷/모 추가 차례를 사용한다. 결제와 구매 처리는 비활성이다.

## 구현

- `functions/src/yut/`에 서버 권위 시작·던지기·비공개 선택·말 이동·시간 초과·종료 명령을
  둔다. 기존 게임 명령 transaction과 재접속·퇴장 처리를 연결한다.
- `packages/game_yut/`은 세 게임 ID를 제공한다. 공개 보드는 태블릿, 비공개 선택과 말
  이동은 휴대폰에 둔다. 태블릿 배치는 기존 전략 윷놀이 HTML의 좌우 점수 영역, 중앙 보드,
  우측 윷 결과·기록 구성을 따른다.
- 일반판은 크림·먹색·주홍색, 에디션은 남청·금색으로 분리한다.
- 시작 준비 barrier와 공용 세션 복구 컨트롤러에 연결한다.
- 일반 윷놀이 차례에는 휴대폰에 표시된 네 윷을 흔들어 던진다. Android
  accelerometer와 iOS Core Motion을 내부 EventChannel로 읽고, 흔들 때 중간 진동을
  반복하며 흔들림이 480ms 멈추면 기존 서버 던지기 명령을 한 번 호출한다. 센서가
  없거나 흔들기를 사용할 수 없는 경우 버튼 던지기도 제공한다.
- 공개된 서버 결과의 `actorUid`, 자리 번호와 윷 면을 사용해 태블릿 보드에 네 윷이
  해당 플레이어 자리에서 중앙으로 날아오게 한다. 네 언어의 휴대폰 안내 문구를 넣었다.

## 현재 상태

- 구현 및 게임 레지스트리 연결 완료.
- Functions TypeScript build는 통과했다.
- Dart analyzer는 `No issues found!`를 출력했다. Dart CLI가 sandbox 밖 사용자 telemetry
  파일의 수정 시간을 기록하지 못해 프로세스 종료 코드는 1이었다.
- 일반 윷놀이 휴대폰 흔들기·진동 및 태블릿 던지기 연출을 추가했다. 변경 화면의 analyzer도
  `No issues found!`였으나 같은 telemetry 오류로 exit 1이다. Android Gradle 컴파일은
  sandbox 밖 `~/.gradle` wrapper lock 권한 오류로 시작하지 못했다. iOS/실기기 빌드와
  센서·진동 동작 확인은 아직 하지 않았다.
- 자동 테스트와 `dart run :mosigame validate --full`은 실행하지 않았다.
- 상품은 카탈로그 후보에서 `enabled: false`, `accessType: paid` 상태다. 운영 Firestore 쓰기,
  배포, 결제 활성화는 하지 않았다. 실제 사용자에게 공개하려면 별도 출시 승인이 필요하다.
