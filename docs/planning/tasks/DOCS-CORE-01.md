현재 분류·상태·다음 행동은 작업 목록을 기준으로 확인한다. 아래 날짜가 붙은 상태·결정은 당시 기록이다.

**핵심 구조·개발·운영 문서 정비**

- 목적: 개발자와 에이전트가 현재 구현을 이해하고 안전하게 수정·검증할 수 있도록 한다.
- 다음 행동: 기존 아키텍처·개발·운영 문서와 코드·테스트의 누락·불일치를 확인한다.
- 완료 조건: 런타임 책임, 핵심 흐름, 권한·데이터·상태 전환의 경계, 검증·운영 경로를
  설명하고 실제 코드·테스트 링크와 확인 기준 커밋을 남긴다. 문서 목차와 AGENTS.md는
  같은 기준 문서로 안내한다. 일지 재분류만으로 이 구현 설명 작업을 완료하지 않는다.
