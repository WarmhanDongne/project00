**기능별 상세 구현 문서화**

- 목적: 핵심 구조 설명을 넘어 기능별 처리 흐름과 설계 이유를 개발자·에이전트가 참조한다.

  보완하고 확인 기준 커밋을 적는다. 확인되지 않은 설계 의도는 추정하지 않는다.
