# newgui 리디자인 · 기능 변화 정리

`newgui` 브랜치에서 디자인 시안(모시겜 게임 목록 캔버스)을 앱에 입히면서 생긴
**기능 변화**, **기능은 있는데 UI가 없어진 것**, **UI는 있는데 기능이 없는 것**을
정리한다. 원칙은 "우선 디자인만 입히고, 바뀐 점은 이 문서에 남긴다"이다.

- 적용 범위: 로그인·회원가입, 태블릿 선반(홈)·게임 상세·상점, 휴대폰 홈·그룹 참여·
  닉네임·대기실, 자리 배치·자리→게임 전환, 게임 안에서는 **태블릿 설정·룰북,
  휴대폰 나가기·룰북 모달만**.
- 손대지 않은 것: 그 밖의 게임 안 화면 전부, 재연결/네트워크 안내 오버레이
  (`GameReconnectScreen`·`NetworkUnavailableModal` 등), 게임별 전용 모달.

## 1. 기능 변화 (동작이 달라진 것)

| 영역 | 변경 | 비고 |
| --- | --- | --- |
| 방 캐릭터 | **기존 저장 ID 17개 + 새 포커페이스 그림** | 이미지 이름을 서버 ID로 보내지 않음. 새/옛 저장값은 같은 얼굴로 읽음. 대응 ID 없는 그림 3개는 읽기·장식 전용으로 보존. |
| 캐릭터 중복 판정 | 예전 id와 새 id가 같은 얼굴이면 같은 캐릭터로 보고 중복 선택을 막음 | 휴대폰 닉네임 화면 |
| 닉네임 길이 | 입력 최대 12자 → **8자** | 계정 프로필·회원가입·방 닉네임. DB 규칙(≤12)은 그대로라 기존 9~12자 닉네임은 계속 표시됨. |
| 이메일 도메인 | 입력칸·선택칸 높이 및 팝업 폭/위치 통일 | 직접 입력의 화살표는 값을 바꾸지 않고 목록을 열며, 전체 주소 입력 때 사용하지 않는 선택칸은 숨김. |
| 로그인·회원가입 전환 | 가입 route push → **같은 인증 화면 안 내용 전환** | 배경·로고·카드는 유지하고 내용만 짧은 fade/slide로 교체. 가입 취소 시 로그인 입력값 유지, 시스템 뒤로 가기는 기존 가입 중단 확인 제공. 인증 링크·서버 온보딩 상태는 AuthGate가 계속 소유. |
| 휴대폰 입장 피드백 | 캐릭터 목록 맨 아래 오류 → **입장 버튼 바로 위 고정 안내** | 입장 중 문구·로딩과 중복 요청 차단을 제공. 서버 오류가 스크롤 아래에 숨지 않게 함. 실제 기기의 입장 거부 원인은 오류 문구 확인 전 미확정. |
| 태블릿 홈 | 게임 카드 그리드 + 미리보기 모달 → **선반**(가운데 상자, 양옆 옆면) + **로비 안 게임 상세** | 자세히 보기·선택된 커버는 왼쪽 상세만 열고 공통 머리줄과 방 패널은 유지. 상세에서 방을 생성해도 게임 선택을 전달하며, 선택/해제를 순서대로 처리. |
| 게임 고르기 | 검색·장르 필터 → **"지금 N명이 할 수 있는 게임만" 토글** | 인원 판정은 기존 시작 조건(`supportedPlayerCounts`, min/max)과 같음. 책 클릭과 느린 좌우 스와이프로 게임 변경, 원래 고정 순서·양 끝 경계 유지. 참가자가 없을 때는 인원 필터를 적용하지 않음. |
| 방 카드 시작 버튼 | 없음 → 선반·상세 오른쪽 카드에 **"N명으로 시작하기"** | 두 화면 모두 선택된 게임의 에셋 준비→게임 선택 완료→자리 배치를 실행. 처리 중 버튼 위치와 로딩 표시 유지. |
| 상점 반응형 배치 | 화면 전체 고정 비율 축소 제거 | 배경은 화면을 채우고, 머리줄은 로비와 같은 44px 버튼 및 16/32px 안전 여백. 책 4권 영역만 비율 유지 축소. |
| 상점 디자인 '모시 서점(신간 매대)' | 미술관 액자 → 서점 매대 | 2026-10-08 시안 A 적용: 뒷벽 책장·걸린 간판(제목 '모시 서점')·매대 위 책 표지·점원 쪽지·계산대 정보 카드. 보유 표시는 빨간 점 → 빨간 책갈피, 상태는 노란 꼬리표로 분리. 손글씨 글꼴(Nanum Pen Script)은 번들하지 않아 본문 굵은 글꼴로 대체. 표지는 선반과 같은 게임 표지 그림을 사용. 동작(선택·마피아 예고편·선반에서 하기·준비 중 안내)은 그대로. |
| 연결 끊김 화면 6종 | 반투명 카드·연보라 대기 화면 → 장면+시트 | 2026-10-08 시안 '연결 끊김' 적용(`game_kit/mosi_ui/mosi_connection.dart`). 휴대폰은 위 장면·아래 흰 시트, 태블릿은 왼쪽 장면·오른쪽 패널. ① 내 인터넷 끊김(`NetworkUnavailableModal`, 문구 '인터넷 연결이 끊겼어요') ② 게임 중 태블릿 끊김(`ControllerReconnectGuard`) ③ 앱 다시 켰을 때(`SessionReturnPrompt`) ④ 대기실 태블릿 끊김(`LobbyReconnectGuard`, 의자에 실제 참가자 얼굴) ⑤⑥ 다른 참가자 끊김(`GameInterruptionLayer`, 남은 시간 고리·동의 표시). 재시도·자동 재연결·투표·제외·즉시 종료·자동 만료 동작은 그대로. ⑤⑥은 이제 게임 화면을 반투명이 아니라 불투명 남색 장면으로 덮음. |
| 로비 서버 연결 띠 | 없음(로비에서는 10초 뒤 모달만) → **화면 맨 아래 가장자리 띠** | 2026-10-10 시안 '서버 연결 알림' 2안 적용(`game_kit/mosi_ui/mosi_connection_band.dart`). 태블릿 로비·휴대폰 홈·대기실만, 게임 화면 제외. `.info/connected`가 1.5초 넘게 끊기면 빨간 '연결이 끊겼어요', 3초 뒤 노란 빗금 '다시 연결하는 중…', 돌아오면 초록 '다시 연결됐어요' 1초 뒤 사라짐. 화면을 막지 않으며 기존 연결 끊김 모달(대기실 10초)은 그대로. 4개 언어 문구 추가. |
| 게임 서버 연결 LED 띠 | 게임 휴대폰 화면에 연결 상태 표시 없음(오래 끊기면 모달만) → **화면 맨 아래 LED 띠** | 2026-10-10 시안 '서버 연결 알림 · 하단 LED 띠' 적용(`game_kit/recovery/widgets/game_connection_led.dart`). 라이어스 포커·홀덤·파이널콜·마피아 휴대폰에 같은 구조, 게임별 색(마피아는 '통신이 끊겼다/다시 잇는 중…/통신 복구'). 7세그먼트 `oFF` → `n-5` → `on`. 로비 띠와 같은 시간표(1.5초 유예 → 끊김, 3초 뒤 다시 연결 중, 복구 1초). `n-5`의 n은 앱 재시도 간격(1·2·4·8초) 기준 **경과 시간으로 계산한 단계**이고 Firebase SDK의 실제 재시도 횟수가 아님. 태블릿 게임 화면에는 넣지 않음. 기존 끊김 모달·중단 투표는 그대로. |
| 로비 반응형 배치 | 공통 머리줄 + 내용/방 패널 | 폭 1,000 미만은 간격·방 패널 폭을 줄이고, 760 미만은 세로 스크롤 배치. 선반 그림만 비율을 유지해 축소. |
| 방 QR | 참가자가 없을 때 큰 초대 QR(확대 불가) → **항상 같은 크기 QR, 누르면 확대** | 참가자 0명일 때는 "QR을 찍으면 여기에 이름이 떠요" 안내. |
| 자리 배치 | 끌어서 맞바꾸기 → **끌기 + 눌러 고른 뒤 다른 카드 눌러 맞바꾸기 + 섞기** | 저장되는 좌석 형식·서버 호출은 동일. |
| 자리→게임 전환 | 카드가 화면 밖으로 날아가고 의자가 밖에서 들어옴 → **카드가 제자리에서 작아지고, 같은 자리에 의자+얼굴이 나타남, 게임 그림이 원형으로 퍼짐** | 타이밍(2.3초 + 1초 대기 + 0.65초 줌)·서버 준비 순서·실패 시 되감기는 동일. |
| 휴대폰 대기실 | 자리 배치 중에도 룰북/곧 시작 화면 → 방 상태가 `seating`이면 **"태블릿에서 자리를 맞추고 있어요"** 화면 | |
| 휴대폰 로비 재접속 | 태블릿 재접속 배너 → **차단형 안내 모달 + 그룹 나가고 홈으로** | 자리 배치 대기에도 표시. 복구되면 자동 닫힘. 퇴장 실패 시 재시도 안내를 유지하며, 휴대폰 자체 오프라인 안내가 우선. |
| 공통 버튼 접근성 | 화면 읽기 실행 동작 연결 | 활성 버튼은 접근성 탭으로 실행하고 비활성·로딩 버튼은 실행하지 않음. |
| 태블릿 설정 모달 | 소리 슬라이더 3개 → 3개 + **"모두 음소거/소리 다시 켜기"** | 전체 소리를 0으로 내리고, 다시 켜면 이전 값으로 돌림. 모달을 닫았다 열어도 같은 사운드 인스턴스의 복원값 유지. |
| 태블릿 룰북 | 마크다운 한 장 + 영상 → `# 제목`마다 **장 넘김(탭·이전/다음)** + 영상 **눌러서 재생/멈춤** | 게임이 넘기는 규칙 문구는 그대로. |
| 휴대폰 룰북 | 문단 텍스트 → 문단마다 **번호 칸** + "알겠어요" | |
| 휴대폰 나가기 모달 | "계속 참여 / 나가기" → **"나가기 / 더 놀래요"**, 경고 상자 추가 | 결과값(true=나가기)은 동일. 시안 문구 "방 코드가 있어도 입장할 수 없어요"는 실제 동작과 달라 **"그룹에 다시 들어오려면 방 코드를 입력해야 해요"**로 둠. |
| 프로필 모달 | 시안 ProfileModal: 사진(눌러서 고름)·닉네임(n/8)은 **취소/저장**으로 함께 반영, 계정 칸에 로그아웃·회원탈퇴 | 내 색 삭제, 10px 남색 그림자 유지, 사진 변경·로그아웃·탈퇴 확인 복구. 현재 방 닉네임은 별개로 유지. |
| 파이널콜 게임 화면 'Party Pop' | 카드 그림·흰 배경 → **색으로 꽉 찬 숫자 카드, 남보라 점무늬 바탕, 둥근 연보라 테이블** | 2026-10-08 시안 'C · Party Pop' 적용(`game_final_call/shared/widgets/party_pop.dart`). 서버 명령·상태·점수 규칙은 그대로. 휴대폰 상단바는 내 얼굴·이름·팀 하트 / 지금 할 일 알약(내 차례·다른 사람 차례·CALL 후 제출) / 규칙·나가기. 태블릿은 좌석마다 회전한 이름표(차례=팀 색 테두리, CALL=노란 이름표, 4인은 '팀 · 짝꿍' 줄), 가운데 차례 알약·덱 장수·라운드 안내, CALL은 가운데 노란 폭발. |
| 파이널콜 새 카드 가져오기 | '새 카드' 버튼 → 덱/공개 카드 선택 모달 → 확인 | 오른쪽 패널의 **덱 / 공개 카드 버튼을 누르면 바로 가져옴**. CALL 이후 마지막 교체 차례에 자동으로 열리던 선택 모달도 없앰(같은 패널에 버튼이 늘 보임). 마감·턴 변경 시 오래된 명령을 보내지 않는 검사는 유지. |
| 파이널콜 CALL | 버튼 한 번 탭 → **꾹 눌러서 선언**(0.65초, 버튼 안이 차오름) | 실수 선언 방지. 화면 읽기 사용자는 접근성 탭 한 번으로 선언. |
| 파이널콜 교체/버리기 | 카드 고르면 한 버튼이 '버리기'↔'교체'로 바뀜 → **'(색) (숫자)랑 바꾸기' / '새 카드 버리기' 두 버튼** | 바꾸기는 손패에서 카드를 고른 뒤에만 눌림. 고르면 '바꾸면 14 → 21'과 바뀐 조합을 미리 보여 줌. |
| 파이널콜 점수 표시 | 최종 제출 때만 점수 | 손패 아래에 지금 점수를 만든 카드를 노란 괄호로 묶고 '7 + 7 = 14점' 표시. 다른 사람 차례에는 패널에 내 점수와 **차례 순서**(서버와 같은 좌석 오름차순, 마지막 교체에서는 남은 사람만). |
| 파이널콜 최종 제출 | 빈 선택에서 시작 | **가장 높은 조합을 미리 골라 둠**(라운드마다 한 번, 다 해제해도 다시 채우지 않음). 고른 카드는 초록 체크, 안 고른 카드는 흐리게. |

## 4. 시안과 다르게 구현한 부분

- **방장 줄**: 시안의 플레이어 목록 첫 줄(방장·이 태블릿)은 실제 데이터에 없음(태블릿은
  플레이어가 아님). 휴대폰 참가자만 표시하고, 강퇴(×)와 "초기화"는 유지.
- **"들어오는 중" 줄**: 입장 중인 참가자 상태가 없어 그리지 않음. 빈 자리는 고른 게임의
  최대 인원까지 상세 화면에서만 그림.
- **마피아 예고편 제목 글꼴**: 시안의 Noto Serif KR은 번들하지 않고 IBM Plex Sans KR 굵게로 대체
  (한글 세리프 글꼴 용량이 큼).
- **상점 상세**: 표지 클릭은 선택만 바꾸며, 선택된 표지를 다시 눌러도 상세를 열지 않는다.
  마피아는 아래 계산대의 "자세히 보기" 버튼으로 예고편 페이지를 연다. 다른 게임은
  계산대 카드·"선반에서 하기"로 처리(상점용 게임 상세 모드는 미구현).
- **휴대폰 나가기 모달 얼굴**: 시안은 내 캐릭터. 공용 모달에 `characterId`를 받을 수 있게
  했지만 각 게임 호출부(게임 안 코드)는 바꾸지 않아 지금은 게임별 문 그림이 동그라미 안에 들어감.
- **게임 안 모달 색**: 모달이 게임 id를 모르므로 게임 이름으로 강조색을 고름.
- **자리→게임 전환의 휴대폰 쪽**(시안 EnterMatch 휴대폰 "자리 확정! GAME START")은 게임 화면
  안 연출이라 적용하지 않음.
- **연결 끊김 장면의 얼굴**: ① 내 인터넷 끊김은 내 캐릭터를 알 수 없어 기본 캐릭터, ③ 앱 다시 켰을 때는
  복원 판정 전이라 다른 자리 얼굴은 장식용 고정 캐릭터이고 '내 자리'는 사람 아이콘. ③ 시안의 게임 카드
  (게임 이름·진행 인원)는 복원 판정에 게임 정보가 없어 그리지 않음.
- **연결 끊김 ② 나가기 버튼**: 시안은 처음부터 보이지만 기존 확정(2026-08)대로 20초 뒤에 나타남.
- **연결 끊김 ⑤ 동의 표시**: 시안은 투표자 얼굴이지만 중단 상태에 투표자 캐릭터가 없어 빈 점선 원/체크
  원으로 표시. ⑥ 진행자 화면 왼쪽 아래 '참가자 N명 중 M명 연결됨' 얼굴 줄도 같은 이유로 생략.
- **기존 그림 미사용**: `assets/images/others/network_unavailable` 그림은 이제 쓰지 않지만 삭제하지 않음.
- **마피아 기권 버튼**: 시안 휴대폰 ⑧의 '기권' 칸은 서버가 기권 표를 받지 않아(시간 초과 = 기권) 2026-10-08
  사용자 결정으로 그리지 않음. 개표 화면의 `기권` 줄은 시간 안에 내지 않은 인원.
- **마피아 시민 밤 문구**: 시안 ⑤의 '시민은 밤에 하는 행동이 없습니다'는 옆에서 보면 신분이 드러나 빼고,
  '화면을 켜 둔 채 아침을 기다려 주세요'만 남김(행동을 끝낸 특수직과 같은 풍경).
- **마피아 밤 '동료' 카드**: 시안 ②는 동료를 흐린 카드로 보여 주지만, 기존처럼 동료는 지목 격자에서 빼고 신분
  카드 아래 '동료 · 이름' 줄로 알림. 처형된 본인 화면의 '관전하기' 버튼은 발표가 끝나면 자동으로 관전으로
  넘어가는 기존 흐름이라 그리지 않음.
- **마피아 글꼴·장식**: Black Han Sans·Noto Sans KR은 번들하지 않고 IBM Plex Sans KR로 대체. 얼굴은 방 캐릭터
  그림에 바랜 사진(세피아)·흑백 필터. 태블릿 ?·설정 버튼은 기존 룰북·설정 동작 그대로 네모 버튼으로만 바꿈.
  태블릿 밤의 새 연출(`night_bird`)과 옛 개표판(`tally_view`)은 시안에 없어 지움. 해·달·말풍선 그림 에셋은 남겨 둠.
- **파이널콜 글꼴·얼굴**: 시안의 Jua 글꼴은 번들하지 않고 IBM Plex Sans KR 굵게로 대체. 태블릿
  이름표 얼굴은 시안의 그린 얼굴 대신 실제 방 캐릭터 그림을 팀 색 원 안에 넣음.
- **파이널콜 태블릿 좌석 위치**: 시안은 4인을 위·아래·좌·우에 두지만, 실제 자리 배치와 맞춘 기존
  좌석 좌표(4인은 대각선)를 그대로 씀. 시안의 태블릿 '?'·나가기 버튼 대신 기존 공용 사이드바 유지.
- **파이널콜 태블릿 '교체 중 0:08'**: 남은 시간은 가운데 차례 알약에만 두고, 이름표에는 '차례'/'교체 중'
  꼬리표만 표시. CALL 이후에는 가운데 폭발이 알약 자리를 대신함.
- **파이널콜 그대로 둔 화면**: 라운드 결과 공개(카드 뒤집기·하트 깨짐)는 새 카드·하트·점수 상자만
  입히고 연출은 그대로. 최종 우승 화면(`result_overlay`)·휴대폰 결과 다이얼로그는 시안이 없어 기존
  그대로. 기존 카드·하트·버튼 그림 에셋은 더 쓰지 않는 것이 있지만 삭제하지 않음.

## 5. 배포·후속 작업

1. 캐릭터 그림과 저장 ID를 분리해 **기존 서버 ID 17개로 입장**한다. 기존 작업의
   Functions/rules ID 확장 diff는 보존했지만 이번 호환 수정에는 배포가 필요하지 않다.
   추가 그림 3개를 선택 가능하게 확장하는 배포는 별도 범위다.
2. 복구한 프로필 사진 변경·로그아웃·회원탈퇴를 실제 기기에서 확인. 자동 검사는 대역 사용.
3. 상점 결제(in_app_purchase 등 새 의존성·서버 검증) — 별도 승인 범위.
4. 앱 용량: 글꼴 번들로 약 8.7MB 증가(IBM Plex Sans KR 3종이 대부분).
5. 게임 내부 재연결/네트워크 안내 화면 시안(10 재연결)은 미적용. 휴대폰 로비의
   태블릿 재접속 안내만 별도 모달로 반영했다.
