파란 고리를 누르면 윷 결과를 고르고, 확정 시 선택한 경로를 따라 이동합니다. 나무판 · 바깥 19칸 + 대각선 9칸
1 · 말 선택

낼 수 있는 말에는 파란 고리가 표시됩니다. 대기 말은 옆 진영에서 고릅니다.

2 · 윷 선택과 경로

말을 누르면 가까운 쪽에 결과 팝오버가 뜨고, 결과를 고르면 도착 칸까지 경로 번호가 보입니다.

3 · 같은 칸에 놓인 말

같은 소유자의 말은 한 토큰으로 포개고 `×개수` 배지를 붙입니다. 이동 확정 후에는 한 묶음으로 움직입니다.

  • 확인 1 어느 말이 선택됐는지 잘 보이는가
  • 확인 2 윷 선택창이 말·경로를 가리지 않는가
  • 확인 3 업은 말의 개수와 소유자가 충분히 읽히는가
  • 확인 4 갈림길 이동 경로가 명확한가
