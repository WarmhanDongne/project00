# newgui 서비스 연결 점검 — 2026-10-06

기준: `newgui`, HEAD `09b4c590e0b060d11ee9f26bfe28cf9b64201f17`에 작업 중인 GUI 변경을
포함한 로컬 코드. 로그인/가입, 프로필, 책장/게임 시작, 방 입장, 상점, 공용 설정/룰북의
호출 경로를 확인했다. production 배포 상태·실기기 입장 성공은 확인하지 않았다.
사용자의 실제 장애 원인은 실기기 로그 확인 전 확정하지 않는다. 아래는 로컬 코드와 회귀 검사 기준이다.

## 이번에 수정한 문제

| 문제 | 원인 | 수정·확인 |
| --- | --- | --- |
| 새 캐릭터로 구 서버 입장 거부 | 이미지 파일명(`burger` 등)을 저장 ID로 바꿔 보내지만 기존 서버는 동물 ID 17개만 허용 | 저장 ID와 그림을 분리. 새 입장은 기존 17개 ID만 전송하고 새 그림으로 표시. 전체 ID·에셋 존재·새/옛 ID의 동일 얼굴 판정 및 실제 입장 UI의 전송값 검사 |
| 천천히 책장을 밀면 선택 안 됨 | 손을 놓는 속도만 판정하고 200 미만은 무시 | 이동 거리 또는 속도로 양방향 스와이프 판정. 후속 요청에 따라 순환을 제거하고 원래 순서·양 끝 경계를 유지. 1·2·4·8권 및 연속 조작 검사 |
| 책처럼 보이는데 클릭 반응 없음 | `MosiEmptySpine`은 클릭 동작 없는 장식. 실제 책이 아닌 칸도 여러 권처럼 노출 | 후속 요청으로 원래 빈 칸·책 배치 복구. 빈 칸은 COMING SOON 장식으로 유지. 실제 책 옆면 클릭은 선택, 정면 클릭은 상세 |
| 방이 없거나 인원 0명이면 책이 사라짐 | 이전에 켜 둔 인원 필터를 0명에 그대로 적용 | 참가자가 있을 때만 인원 필터 적용. 방 없이 필터가 남아 있는 상태에서 책 선택·상세 검사 |
| 갱신 중 모든 책 입력 차단 | 그룹 목록을 갱신할 때 이전 책을 그리면서 `IgnorePointer`로 입력 전체 차단 | 유지 중인 목록은 계속 탐색 가능. 실행 가능 여부는 기존 시작·서버 검증 유지 |
| 책 교체·상세 전환이 갑작스러움 | 표지와 옆면을 별도 위젯으로 즉시 교체, 상세는 fade만 적용 | 위치·회전을 하나의 진행 값으로 계산. 고정 순서로 이동하며 정면/옆면만 연속 회전. 상세 시 책장은 왼쪽으로 퇴장, 상세는 오른쪽에서 진입. 방 패널은 전환 밖에 유지 |

캐릭터의 `RoomCharacter.id`와 기존 서버 계약은 유지하며 `assetPath`만 새 그림에 연결한다.
기존 ID가 없는 `cone`, `catcher`, `bandage`는 에셋과 이미 저장된 값의 읽기를 보존하지만
선택 목록에는 넣지 않는다. 20개 모두를 선택 가능하게 하려면 별도 서버 ID 확장·배포와
구버전 호환 검증이 필요하다. 기존 작업에 있던 Functions/rules의 확장 diff는 보존했으며,
이번 클라이언트 호환 수정에 그 변경의 배포가 필요하지는 않다.

## 후속 요청으로 수정한 추가 불일치

| 현상 | 수정 |
| --- | --- |
| 프로필에서 로그아웃·탈퇴·사진 변경 진입점이 빠짐 | 기존 signOut, deleteAccount, uploadProfileImage/createUserDocument 호출 복구. 탈퇴는 명시적 확인 후 요청, 처리 중 중복·닫기 차단, 실패 표시·재시도. 기존 계정 삭제 후 방 세션 정리 유지 |
| 저장되지 않는 ‘내 색’ | 사용자 요청으로 삭제하고 해당 위치에 로그아웃/회원탈퇴 제공. 아바타와 프로필 패널 그림자 제거. 양 기기 프로필의 화면 읽기 탭 실행도 연결 |
| 닉네임이 현재 방 목록도 변경한다고 안내 | 계정 닉네임과 현재 방 닉네임이 별개임을 안내. 방 저장 계약은 유지 |
| 상점이 보유 여부·가격을 고정값으로 표시 | 기존 개인 GameProvider의 isOwned/isFree에 연결. 그룹 보유를 개인 구매로 표시하지 않음. 결제 미연결 가격/구매 확정 연출 제거, 준비 중 안내. 조회 실패는 다시 확인 제공 |
| 상점에서 고른 게임이 홈 선택에 미반영 | 상점/마피아 상세가 게임 ID를 반환하고 홈 선반 선택에 반영. 인원 필터는 해제하여 고른 책이 보이게 함 |
| 액자 이름표를 눌러도 무반응 | 그림뿐 아니라 이름표 영역도 선택 동작 연결 |
| 인증 메일 재전송 대기 안내와 실제 버튼 동작 불일치 | 기존 즉시 재전송 동작에 맞춰 ‘메일이 오지 않았다면 다시 보내 주세요’로 안내 |
| 음소거 후 모달 재개방 때 30 대신 70으로 복원 | 모달 바깥의 사운드 인스턴스별 weak map에 복원값 유지. 영구 저장/공용 API 변경 없음. 앱 재실행 시 복원값까지 보존하는 변경은 아님 |
| 실제 신청/재생 없이 알림 켜짐·음악 재생 중 표시 | 준비 중 표시로 정정. 결제·복원·알림·음악은 여전히 미연결이며 성공 상태를 가장하지 않음 |

상점 진입은 홈 머리줄 위쪽·책장 왼쪽·방 패널 오른쪽 퇴장(180ms), 조명 하강·액자별
등장·하단 안내 진입(480ms)을 연결한다. 진입 중 조명→액자→안내는 같은 시간축에서
겹쳐 실행한다. 모션 감소 설정은 진입/퇴장 애니메이션을 생략한다. 책장의 원래
고정 순서·간격·빈 칸 디자인은 유지한다.

## 남아 있는 미연결 기능

- 실제 구매/복원, 새 게임 알림 신청, 예고편 음악은 별도 서비스 연결이 필요하다.
  이번에는 기존 디자인 안에서 준비 중임을 명확히 표시했다. 결제 SDK·영수증 검증·
  알림 서버 추가나 배포를 하지 않았다.
- 휴대폰 자리 배치의 ‘태블릿에서 내 자리 찾기’는 기존 준비 중 안내이며 신호를 보내지 않는다.
- 프로필 실제 사진 업로드/탈퇴, 양 기기 입장·상점 전환 체감은 실기기에서 미확인이다.
  자동 검사는 대역을 사용하며 실제 계정을 삭제하지 않았다.
