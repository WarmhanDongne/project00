## 3-2. 효과음이 나는 순간

확정(2026-08): 직업 효과음은 **그 직업이 선택을 완료한 순간** 방 가운데
태블릿에서 울립니다. 밤이 시작될 때 자동으로 울리던 총성은 없앴습니다.

| 마피아 승리(`win_mafia.mp3`) | 결과 화면 | 태블릿 |

### 배경음악 (태블릿)

확정(2026-08): **밤에만** 곡이 깔립니다. 규칙은 `mafiaBackgroundMusicFor` 한곳.

| 단계 | 곡 |
|---|---|
| 신분 확인 · 아침 · 낮 토론 · 투표 · 개표 · 결과 | 없음 |
| 밤 | `background/background_night.mp3` |

| 구간 | 시간 | 상수 |
|---|---|---|
| 아침이 될 때 밤 곡이 서서히 사라짐 | 1.6초 | `mafiaBgmFadeOut` |

낮에 곡을 깔지 않는 이유는 목소리를 덮지 않기 위해서입니다. 페이드는 사용자
볼륨 설정을 건드리지 않습니다(설정 볼륨에 곱하는 배율만 내립니다).

서버가 `public.nightActionCue`(행동 종류 + 신호 번호)를 올려 주고 태블릿이
소리로 옮깁니다. **누가 냈는지는 서버도 보내지 않습니다.** 그 사람의
휴대폰에서 울리면 옆 사람에게 신분이 드러나므로 태블릿에서만 냅니다.
대상을 바꿔 다시 제출해도 그 밤에 한 번만 울립니다.

아직 파일이 없어 소리가 나지 않는 행동(파일이 들어오면 `MafiaSounds`에 한 줄):
보호·조사·역할 조사·역할 차단·전향·침묵·추적.

## 5. 문구 목록

### 단계 안내 (태블릿, 화면 가운데 64px)

### 발표 문구 (태블릿·휴대폰 같은 문구)

확정(2026-08): **긴 문장은 두 박자로 나눠** 찍습니다. `→`가 박자 경계이고,
찍는 말투라 마침표는 넣지 않습니다. 나누는 자리는 문장마다 손으로 정합니다
(`MafiaCopy`의 `*Beats`).

| 문구 | 언제 |
|---|---|
| `○○님은` → `밤을 넘기지 못했습니다` | 아침, 사망자 있음 |
| `어제 밤,` → `아무도 죽지 않았습니다` | 아침, 사망자 없음 |
| `오늘의 처형자` | 처형 발표(남이 처형됨) |
| `당신은 처형 당했습니다` | 처형 발표(당사자) |
| `○○` (처형자 이름 한 방) | 처형 발표(태블릿) |
| `○○님이` → `처형되었습니다` | 처형 발표 아래 문구 |
| `처형된 사람이 없습니다` | 아무도 처형 안 됨 |
| `표가 같아` → `아무도 처형되지 않았습니다` | 동표로 무효 |
| `○○님은` → `○○이었습니다` | 처형자 신분 공개(카드 절반 뒤집힌 뒤) |
| `○○님의` → `신분을 확인할 수 없습니다` | 이 빌드가 모르는 신분 |

### 휴대폰 조작 문구

| 문구 | 화면 |
|---|---|
| `당신은 ○○입니다` + 역할 설명 | 신분 카드 |
| `제거할 대상을 선택하세요`(역할별 동사) | 밤 행동 |
| `선택 완료` | 밤 행동·투표 버튼 |
| `선택을 완료했습니다` | 밤 제출 후(밤에 하는 일이 있는 신분만) |
| `다른 플레이어의 행동을 기다리는 중…` | 밤 대기 |
| `조사 결과` / `추적 결과` | 경찰·탐정 결과 |
| `확인` | 결과 확인 버튼 |
| `자유 토론` | 낮 (문구 묶음이 삽화 쪽으로 36px 내려와 있습니다) |
| `토론 종료 하기` → `3/6` | 조기 종료(누르면 집계·비활성) |

| `다른 플레이어의 투표를 기다리는 중입니다…` | 투표 후 |
