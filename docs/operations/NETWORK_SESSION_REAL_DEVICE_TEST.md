# 네트워크·세션 변경 후 실기기 테스트

2026-10-09 작성. 아래 항목은 아직 실기기에서 실행하지 않았다.
현재 개발한 앱과 테스트 서버 준비는 [설치·배포 준비](NETWORK_SESSION_TEST_PREPARATION.md)를 따른다.
이 문서에서는 기기 조작과 화면만 확인한다. 서버 조회, 로그 읽기, 검토 ID 입력은 없다.

## 시작할 때 한 번만 준비

- Android 태블릿 1대와 휴대폰 2대에 같은 APK를 설치하고 각각 다른 테스트 계정으로 로그인한다.
  서버는 기존 Firebase를 사용한다. [설치·배포 준비](NETWORK_SESSION_TEST_PREPARATION.md)의 준비 완료를 확인한다.
- 주로 끊을 휴대폰을 **A**, 비교할 정상 휴대폰을 **B**라고 부른다.
- 추가 휴대폰이 모이는 날만 **C·D**를 사용한다. 평소에는 필요 없다.
- 태블릿에서 새 그룹을 만들고 휴대폰들이 참가한다. 기존 운영 중인 방은 사용하지 않는다.
- 기기 이름·Android 버전과 테스트 날짜는 시작할 때 한 번만 적으면 된다.
- 게임은 이미 테스트 권한이 준비된 것을 사용한다. 이 테스트 때문에 실제 결제를 하지 않는다.
- 앱 삭제·데이터 지우기는 하지 않는다. 저장된 참가 정보의 복구도 확인해야 한다.

**인터넷 끄기:** 비행기 모드를 켠 뒤 Wi-Fi도 꺼져 있는지 확인한다.
비행기 모드만 켜고 Wi-Fi가 살아 있으면 단절 테스트가 아니다. 인터넷을 켤 때는 원래 연결로 복구한다.
**앱 강제 종료:** 설정 → 앱 → Mosigame → 강제 종료를 사용한다. 홈 버튼만 누르는 것과 구분한다.

각 항목 제목의 체크는 조작과 확인 결과를 모두 확인했을 때만 표시한다.
못 한 항목은 그대로 두고 이유만 적는다. 문제가 있으면 **게임 / 기기 / 직전 조작 / 화면 증상**만
짧게 적거나 화면을 촬영한다. 손패·역할은 본인이 비교하고, 공유 영상에서는 계정 정보를 가린다.

**관찰 기준:** 인터넷을 끈 즉시 모든 기기가 동시에 알아채지는 않을 수 있다.
게임 타이머는 태블릿에 `게임을 잠시 멈췄어요`가 뜬 순간부터 비교한다.
그 전에 조금 흐른 시간과 중단 이후 계속 감소하는 문제를 구분한다.
복구는 인터넷을 켠 뒤 실제 게임 조작이 가능해질 때까지 본다.
60초 이상 계속 보호 화면이면 화면 문구와 `다시 시도` 결과를 남긴다. 60초는 성능 합격선이 아니라 관찰 구간이다.

## 먼저 할 필수 확인 — 태블릿 1대 + 휴대폰 2대

아래 여섯 항목은 **라이어스포커와 홀덤에서 각각** 확인한다.
중단·복구 항목은 같은 게임에서 이어서 진행하고, 종료된 뒤 다음 게임을 시작한다.
뒤의 파이널콜·마피아에서도 같은 순서로 확인하되, 마피아의 손패/칩 비교는 본인 역할·생존 여부·현재 단계 비교로 바꾼다.

### 정상 시작·행동·자리 배치

- [ ] 정상 흐름 확인

1. A·B가 같은 그룹에 참가한다. 태블릿에 두 사람의 닉네임·자리와 그룹 코드가 맞는지 본다.
2. 자리 배치를 바꾸거나 앱에 제공된 무작위 자리 배치를 사용한다. 해당 기능이 없으면 이 조작만 생략한다.
3. 게임을 시작하고 A·B가 각자 자신의 손패를 볼 수 있는지 확인한다.
4. 각자의 차례에 게임 규칙상 가능한 행동을 하나씩 한다.

**확인:** 같은 게임·차례·참가자 상태를 보여야 한다. 카드/칩이 두 번 처리되거나 시작 화면에 멈추지 않는다.
내 차례가 아닌 행동과 다른 사람의 비공개 정보는 사용할 수 없다.

### 휴대폰 단절·복구를 같은 게임에서 두 번

- [ ] 휴대폰 반복 복구 확인

1. A의 손패와 현재 차례를 기억하고, 보이는 게임 타이머가 있다면 숫자를 적는다.
2. A의 인터넷을 끈다. A의 화면에 보호 안내가 뜨면 카드 제출·베팅 등 진행 버튼을 눌러 본다.
3. 태블릿에 게임 중단 화면이 뜨면 그때의 게임 타이머 숫자를 기억하고 **10초 더 기다린다**.
4. A의 인터넷을 켠다. 안내가 사라지고 필요한 화면이 준비된 뒤 A의 합법적인 행동을 한 번 한다.
5. 새 게임을 만들지 않고 A의 다음 차례에 같은 조작을 한 번 더 한다.

**확인:** 보호 중 행동이 실행되지 않는다. 같은 방·자리·손패로 돌아오고 B도 그대로 남는다.
중단 때 남은 시간이 보존돼야 하며 중단 화면의 복구 대기 숫자는 게임 타이머와 구분한다.
복구마다 전체 턴 시간이 처음부터 다시 생기거나, 중단 중 기다린 시간이 차감되면 문제다.

### 태블릿만 단절·복구

- [ ] 태블릿 복구 확인

1. 휴대폰 인터넷은 유지하고 태블릿의 인터넷만 끈다.
2. 휴대폰에 태블릿 연결/게임 중단 안내가 나오면 게임 진행 버튼을 눌러 본다.
3. 중단 안내가 나온 뒤 10초 기다렸다가 태블릿 인터넷을 켠다.
4. 같은 게임이 준비된 뒤 현재 차례의 휴대폰에서 행동을 한 번 한다.

**확인:** 태블릿 문제 때문에 휴대폰이 강제로 그룹에서 나가거나 새 방이 생기지 않는다.
준비되기 전에 게임이 진행되지 않고, 복구 뒤 기존 손패·칩·차례가 이어진다.

### 휴대폰 앱을 종료하고 다시 참여

- [ ] 휴대폰 재실행 확인

1. 게임 중 A의 손패·자리를 기억하고 A 앱을 강제 종료한다.
2. 태블릿에서 중단을 확인한 뒤 A 앱을 다시 연다.
3. `진행 중인 게임이 있어요` 화면에서 **아직 아무 버튼도 누르지 않고** 잠깐 기다린다.
4. `게임 다시 참여`를 누른다. 대기실에 잠깐 들렀더라도 현재 게임까지 열리는지 본다.

**확인:** 동의 전에 자동으로 게임에 참가하지 않는다. 선택 뒤에는 기존 자리·손패를 복원하고
참가자가 두 명으로 중복 표시되지 않는다. 본인 화면의 준비가 끝난 뒤 행동이 가능해야 한다.

### 태블릿 앱을 종료하고 다시 열기

- [ ] 태블릿 재실행 확인

1. 진행 중인 게임에서 태블릿 앱을 강제 종료한다. 휴대폰 앱은 그대로 둔다.
2. 휴대폰에서 중단 안내를 확인한다.
3. 태블릿 앱을 다시 연다. 새 그룹 만들기는 누르지 않는다.
4. 기존 그룹·진행 중인 게임이 돌아오면 현재 차례의 휴대폰에서 한 번 행동한다.

**확인:** 태블릿은 기존 그룹을 자동 복원한다. 휴대폰의 손패·칩·자리가 유지되고 새 게임으로 시작하지 않는다.
태블릿 복원만으로 준비되지 않은 휴대폰까지 강제로 진행시키지 않는다.

### 정상 결과·대기실·다음 게임

- [ ] 정상 종료 뒤 다음 게임 확인

1. 게임을 정상적으로 끝내고 태블릿·휴대폰의 결과를 본다. 홀덤은 한 핸드 정산과 전체 게임 종료를 구분한다.
2. 결과 화면의 나가기/대기실 복귀 버튼을 누른다.
3. 남은 기기들도 그룹 대기실로 돌아오는지 본다.
4. 태블릿에서 다음 게임을 선택해 시작한다. 종료한 게임과 다른 게임도 한 번 선택한다.

**확인:** 결과가 중간에 사라지지 않고, 종료 뒤 검정 화면·이전 게임 화면·중복 복귀가 없다.
휴대폰은 플랫폼 홈에서 세로, 태블릿은 가로로 돌아오며 새 게임에 이전 손패·결과가 남지 않는다.

## 기본 기기로 추가 확인 — 태블릿 1대 + 휴대폰 2대

아래는 우선 라이어스포커에서 한 번씩 한다. 홀덤 전용 항목은 홀덤에서 한다.
확인하지 않은 다른 게임·OS까지 통과했다고 확대하지 않는다.

### 대기실에서 각각 끊었다가 복구

- [ ] 게임 시작 전 복구 확인

1. 새 그룹에 A·B가 참가한 뒤 게임은 아직 시작하지 않는다.
2. A 인터넷을 20초 끊었다가 켠다. 같은 닉네임·자리로 돌아오는지 본다.
3. 모두 정상인 상태에서 태블릿 인터넷도 20초 끊었다가 켠다.
4. 기존 그룹 코드가 유지되는지 보고 게임을 시작한다.

**확인:** 참가자 중복, 자동 퇴장, 새 방 생성 없이 같은 그룹에서 시작할 수 있다.

### 여러 기기가 끊기고 서로 다른 순서로 복귀

- [ ] 마지막 기기까지 기다리는지 확인

1. 게임 중 A를 끊고 중단 안내를 확인한다. 이어서 B도 끊는다.
2. A만 인터넷을 켠다. B가 끊긴 상태에서 A의 진행 버튼을 눌러 본다.
3. B도 인터넷을 켠다. 모두 준비된 뒤 게임이 이어지는지 본다.
4. 다음 차례에는 A·B·태블릿을 모두 끊는다. A·B만 복구하고, 마지막에 태블릿을 복구한다.
5. 한 번 더 할 수 있으면 태블릿을 먼저 복구하고 A·B를 나중에 복구한다.

**확인:** 아직 필수 기기가 끊겨 있거나 화면 준비 중이면 진행하지 않는다.
두 번째 단절이 최초 게임 타이머를 새로 초기화하지 않으며, 안내가 여러 겹 쌓이지 않는다.

### 인터넷이 없는 상태로 앱 시작

- [ ] 오프라인 시작 후 저장된 게임 복구 확인

1. 게임에 참가한 A 앱을 강제 종료한다. A 인터넷을 끈 채 앱을 다시 연다.
2. 10초 기다린 뒤 인터넷을 켠다. 앱을 또 재실행하거나 방 코드를 다시 입력하지 않는다.
3. 기존 게임 복귀 질문이 나오면 `게임 다시 참여`를 누른다.
4. 새 게임에서 같은 순서를 태블릿에도 적용한다. 태블릿은 복귀 동의 버튼 없이 기존 그룹을 복원해야 한다.

**확인:** 처음에 인터넷이 없었다는 이유로 저장한 방을 잊지 않는다.
인터넷이 돌아온 뒤 같은 그룹·게임으로 갈 수 있고, 새 그룹을 만들도록 강요하지 않는다.

### 백그라운드·화면 잠금에서 복귀

- [ ] 앱 전환과 잠금 후 복구 확인

1. A에서 홈 화면이나 다른 앱으로 이동해 30초 기다린 뒤 Mosigame으로 돌아온다.
2. 다음 차례에는 A 화면을 잠그고 30초 뒤 풀어 돌아온다.
3. 태블릿에서도 다른 앱 전환과 화면 잠금을 각각 한 번 한다.
4. 복귀한 화면이 준비된 뒤 현재 차례의 행동을 한다.

**확인:** OS가 연결을 유지했다면 중단 안내가 없어도 정상이다. 중단이 감지됐으면 준비 후 재개해야 한다.
기존 손패·자리가 유지되고, 복귀 직후 옛 화면을 눌러 현재 게임에 잘못된 행동을 보내지 않는다.

### 네트워크 전환과 복구 직후 다시 단절

- [ ] 연결 전환·재단절 확인

1. A에서 Wi-Fi를 끄고 모바일 데이터로 바꾼다. 다시 Wi-Fi로 돌아오는 조작을 두 번 한다.
2. 다음에는 인터넷을 완전히 끄고 중단을 확인한다.
3. 인터넷을 켜고 화면이 돌아오기 시작할 때 1~2초 안에 다시 끈다.
4. 잠시 기다렸다가 인터넷을 켜고 게임을 계속한다.

**확인:** 순간 전환으로 강제 퇴장하지 않는다. 마지막 연결의 화면이 준비된 뒤에만 행동할 수 있다.
옛 연결의 안내가 뒤늦게 다시 뜨거나 손패가 이전 값으로 되돌아가지 않는다.

### 복구 대기 만료·한 번 더 기다리기

- [ ] 만료 뒤 진행자 선택 확인

1. A 인터넷을 끄고 태블릿 중단 화면의 복구 대기 숫자가 0이 될 때까지 기다린다.
2. 10초 더 기다린다. 태블릿이나 B에서 아무 종료 버튼도 누르지 않는다.
3. 태블릿의 `30초 더 기다리기`를 빠르게 두세 번 누른다.
4. 연장된 대기가 끝나기 전에 A 인터넷을 켠다.
5. 별도 시도에서는 A를 복구하지 않고 연장된 대기도 끝까지 기다린다.

**확인:** 기본 대기나 연장 대기가 끝났다는 이유만으로 참가자를 삭제하거나 게임을 종료하지 않는다.
한 번만 약 30초 연장되며 반복 탭으로 누적 연장되지 않는다. A가 준비되면 기다리던 선택 화면이 닫힌다.
B에는 타인을 제외하거나 전체 게임을 종료하는 버튼이 없어야 한다.

### 진행할 수 없는 참가자 제외·종료 확인

- [ ] 인원 부족 보호와 종료 확인

1. 2인 라이어스포커 또는 홀덤에서 A를 끊는다.
2. 태블릿의 `제외하고 계속하기`와 인원 부족 안내를 확인한다.
3. `게임 종료`를 한 번 누르고 `계속 기다리기`를 눌러 취소한다.
4. 다시 `게임 종료` → `종료 확인`을 누른다.

**확인:** 남은 인원으로 진행할 수 없으면 제외 버튼이 비활성이고 이유가 보인다.
첫 종료 탭이나 취소만으로 끝나지 않는다. 확인 후 남은 기기가 종료 안내·대기실로 한 번만 이동한다.

### 복구 질문 거절

- [ ] 다시 참가하지 않기로 한 선택 확인

1. A 앱을 강제 종료한 뒤 다시 열어 복귀 질문에서 `나중에`를 선택한다.
2. A는 홈에 머무는지 본다. 태블릿도 A의 퇴장 결과가 반영되는지 본다.
3. A 앱을 한 번 더 종료·재실행한다.
4. 나중에 A가 직접 그룹 코드를 입력해 다시 참가한다.

**확인:** 거절 뒤 자동으로 옛 게임에 참가하거나 복귀 질문을 계속 반복하지 않는다.
새로 직접 참가한 자리를 옛 퇴장 작업이 뒤늦게 지우지 않는다. 인원 부족으로 이전 게임이 종료될 수 있다.

### 연결된 상태에서 나가기·다시 참가

- [ ] 자기 퇴장과 재가입 확인

1. 게임 중 A에서 메뉴의 `게임과 그룹 나가기` 또는 중단 안내의 `내가 나가기`를 선택한다.
2. 같은 나가기 버튼을 빠르게 두 번 누른다.
3. 홈에 도착하면 앱을 다시 열어 자동 복귀하지 않는지 본다.
4. 필요하면 이전 게임을 정상 종료하고 A가 직접 같은 그룹에 다시 참가한다.

**확인:** 퇴장이 중복 처리되거나 홈 화면을 여러 번 닫지 않는다. 태블릿 명단에서 A의 기존 참가가 사라진다.
B는 게임 규칙에 맞게 계속하거나 인원 부족 종료 안내를 받는다. 재가입한 A가 다시 튕기지 않는다.

### 인터넷 없는 상태에서 나가기·앱 재실행

- [ ] 미확정 퇴장이 복귀보다 우선하는지 확인

1. A 인터넷을 끄고 보호 화면에서 본인 나가기를 누른다.
2. 처리 중이나 결과 확인 안내가 있어도 A 앱을 강제 종료한다.
3. 인터넷을 켜고 A 앱을 다시 연다.
4. 태블릿에서 A의 기존 참가가 정리되는지 본다. 이후 A가 직접 다시 참가해 본다.

**확인:** 인터넷이 없어 바로 홈으로 이동하지 못할 수 있다. 그러나 재실행 후 옛 게임에 자동 참가하거나
복귀 동의를 받아 퇴장 의도를 뒤집으면 안 된다. 연결 복구 후 퇴장 결과를 정리하고 홈을 사용할 수 있어야 한다.

### 대기실에서 강퇴·그룹 닫기

- [ ] 종료된 참가·그룹을 되살리지 않는지 확인

1. 게임을 종료해 대기실로 돌아온다. 태블릿의 참가자 관리에서 A를 내보낸다.
2. A에서 인터넷을 끊었다 켜고 앱도 다시 열어 본다.
3. A가 직접 다시 참가한 뒤 태블릿에서 그룹을 닫는다.
4. 태블릿은 새 그룹을 만들고 A·B가 새 그룹에 참가한다.

**확인:** 강퇴된 A가 자동으로 되살아나지 않는다. 닫힌 그룹은 복구 대상이 아니다.
새 그룹의 참가자·화면이 옛 그룹의 늦은 정리 때문에 사라지지 않는다.
해당 화면에 관리/닫기 기능이 없으면 기능을 찾으려고 서버를 수정하지 말고 그 조작만 미실행으로 남긴다.

### 결과 화면에서 태블릿 앱 재실행

- [ ] 종료와 재실행이 겹치는 경우 확인

1. 게임을 정상 종료해 휴대폰의 결과 화면을 띄운다.
2. 태블릿에서 대기실 복귀 버튼을 누르기 전에 태블릿 앱을 강제 종료한다.
3. 태블릿 앱을 다시 열고 A·B 화면도 본다.
4. 태블릿에서 다음 게임을 선택한다.

**확인:** 진행이 끝난 게임을 새로 진행하지 않는다. 기존 그룹 대기실과 다음 게임 선택을 사용할 수 있고
휴대폰도 검정 화면이나 이전 결과 화면에 영구히 남지 않는다.

### 홈의 상세 화면과 복구 질문

- [ ] 다른 화면을 강제로 닫지 않는지 확인

1. A가 게임에 참가한 상태에서 앱을 종료하고, 인터넷을 끈 상태로 다시 연다.
2. 아직 복귀 질문이 없는 홈에서 게임 상세 또는 스토어를 연다. 열 수 없으면 이 항목은 미실행으로 남긴다.
3. 상세 화면을 열어 둔 채 인터넷을 켠다. 뒤로가기/닫기로 홈에 돌아온다.
4. 복귀 질문에서 `게임 다시 참여`를 누르고, 나중에 정상 종료한다.

**확인:** 복구가 상세 화면을 강제로 닫거나 부모 홈까지 지우지 않는다.
홈으로 돌아온 뒤 복귀 선택이 한 번 나타나며, 게임 종료 뒤 잘못된 화면을 추가로 닫지 않는다.

### 로그인 유지·계정 전환

- [ ] 로그인과 저장 참가 정보의 소유자 확인

1. 로그인된 앱을 인터넷 없는 상태에서 열었다가 인터넷을 켠다.
2. 로그인/홈으로 돌아갈 수 있는지 보고 무한 로딩이나 오류 안내가 계속 남는지 본다.
3. A가 그룹에서 정상 퇴장한 뒤 로그아웃하고 다른 테스트 계정으로 로그인한다.
4. 새 계정으로 새 그룹에 참가하고 앱을 재실행한다.

**확인:** 이전 계정의 복귀 질문·닉네임·손패가 새 계정에 섞이지 않는다.
온보딩을 마친 기존 계정을 새 가입으로 잘못 안내하지 않는다.
계정 교체를 위해 기존 운영 계정을 삭제하거나 회원 탈퇴하지 않는다.

### 홀덤 올인·폴드·다음 핸드

- [ ] 홀덤의 역할별 복구 확인

1. A가 현재 핸드에서 올인하도록 플레이한다. 정산 전에 `내 칩`이 0인 상태를 만든다.
2. A 인터넷을 끊고 중단을 확인한 뒤 복구한다.
3. 해당 핸드를 정산하고 다음 핸드까지 진행한다.
4. 다른 핸드에서는 A가 폴드한 뒤 앱을 재실행하고 다시 참여한다.

**확인:** 정산 전 올인·칩 0인 A를 이미 탈락한 사람처럼 제거하지 않는다. 카드·팟·정산이 유지된다.
다음 핸드의 참가 가능 여부는 정산 결과에 따른다. 폴드 복구로 다시 행동하거나 이미 낸 칩이 중복 처리되지 않는다.

### 이미 받은 게임 파일로 복구

- [ ] 정상 캐시를 다시 다운로드하지 않는지 확인

1. 홀덤을 한 번 정상적으로 시작해 필요한 다운로드가 끝나게 한다.
2. 네트워크 단절·복구와 앱 종료·재참여를 각각 한 번 한다.
3. `게임 파일을 복구할까요?`가 정상 파일에도 반복해서 뜨는지 본다.

**확인:** 정상적으로 준비된 파일로 기존 게임에 돌아오며, 매번 다운로드나 결제를 다시 요구하지 않는다.
파일 손상을 일부러 만들려고 앱 데이터를 지우지 않는다. 손상·저장 실패를 만드는 작업은 담당자가 별도로 준비한다.

## 추가 휴대폰이 모이는 날의 필수 묶음

파이널콜은 4명, 마피아는 최소 4명이 필요하므로 **태블릿 1대 + 휴대폰 A·B·C·D**에서 한다.
휴대폰 2대로 인원을 가짜로 채우지 않는다. 이 묶음 외에는 네 대를 계속 준비할 필요 없다.

### 파이널콜 — 기본 복구와 팀·제출

- [ ] 파이널콜 필수 확인

1. 네 휴대폰을 참가시키고 2대2 자리·팀을 정해 게임을 시작한다.
   파이널콜 휴대폰 화면은 가로다. 종료해 플랫폼 홈으로 돌아온 뒤 세로로 복원되는지도 본다.
2. 앞의 필수 여섯 항목을 한 번씩 확인한다. 태블릿·휴대폰 종료/복구는 같은 게임에서 이어서 해도 된다.
3. 카드를 나눠 주는 화면에서 A를 잠깐 끊고 복구해 카드가 준비되는지 본다.
4. 팀 행동/최종 손패 제출 단계에서 A를 끊었다 복구하고, 표시된 재시도 버튼이 있으면 한 번 누른다.
5. 라운드 결과와 다음 라운드까지 진행한다.

**확인:** 팀·자리·손패가 바뀌지 않는다. 카드 준비 전 보호가 유지되며 정상 준비 후 진행한다.
팀 행동/제출/라운드 전환이 중복되거나, 새 라운드에서 옛 제출 안내가 다시 동작하지 않는다.
같은 인터넷 조작을 여러 타이밍에 시도해도 정확한 응답 유실을 만들었다고 단정하지 않는다.

### 마피아 — 기본 복구와 역할·밤/낮

- [ ] 마피아 필수 확인

1. 네 휴대폰으로 앱이 허용하는 4인 역할 구성을 선택해 시작한다.
2. 앞의 필수 여섯 항목을 한 번씩 확인한다.
3. 역할 공개 때 A 앱을 종료·재참여한다. 같은 역할이 보이는지 확인한다.
4. 밤에 특수 행동이 없는 역할의 휴대폰도 정상 대기할 수 있는지 본다.
5. 행동 가능한 휴대폰은 밤 행동/투표를 한 번 수행하고 밤→아침→낮→투표 화면을 진행한다.
6. 중간에 한 기기를 끊었다 복구한다. 이전 밤이나 이전 투표의 버튼이 다음 단계에서 다시 활성화되는지 본다.

**확인:** 본인 역할이 유지되고 다른 사람의 역할이 노출되지 않는다.
특수 행동이 없는 역할을 준비 실패로 취급하지 않는다. 밤 행동·투표가 중복 처리되지 않고 현재 단계의 조작만 가능하다.

### 마피아 — 죽은 참가자의 단절

- [ ] 생존자와 관전자의 중단 범위 확인

1. 위 마피아 게임에서 참가자 한 명이 죽어 관전 상태가 될 때까지 진행한다.
2. 죽은 참가자의 휴대폰만 인터넷을 끈다. 생존자는 게임을 진행한다.
3. 죽은 참가자의 인터넷을 켜고, 필요하면 앱을 다시 열어 참여한다.

**확인:** 죽은 사람의 단절만으로 생존자 전원이 계속 중단되지 않는다.
본인 휴대폰의 연결 보호는 있을 수 있지만, 복귀로 살아나거나 밤 행동/투표 권한이 생기지 않는다.
조기 승부로 사망 후 진행 상태를 만들지 못했다면 다음 4대 사용 기회에 남긴다.

### 세 명으로 제외 후 실제 계속하기

- [ ] 진행 가능한 참가자 제외 확인

1. 추가 기기 중 C만 더 사용해 라이어스포커를 A·B·C 세 명으로 시작한다. D는 쉬어도 된다.
2. A를 끊고 태블릿의 `제외하고 계속하기`가 활성화되는지 본다. 버튼이 비활성이면 보이는 이유를 남긴다.
3. 활성화돼 있으면 눌러 B·C가 실제로 한 차례씩 진행하는지 확인한다.
4. A 인터넷을 켜고 앱을 다시 열어 옛 게임에 되살아나는지 본다.
5. 같은 절차를 3인 홀덤에서도 한 번 한다.

**확인:** 제외한 A는 현재 게임에 다시 참가하지 않고, B·C는 남은 인원으로 정상 진행한다.
최초에 중단된 사람과 다른 사람을 잘못 제외하지 않는다. 네 대가 동시에 필요한 항목은 아니며 추가 기기가 있는 날 함께 끝낸다.
