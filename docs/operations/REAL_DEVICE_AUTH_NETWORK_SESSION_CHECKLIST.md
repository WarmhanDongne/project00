# 출시 차단 수정 — 필수 실기기 체크리스트

자동으로 재현한 단절·복구 경합, 타이머 중첩 중단, 중복 route 종료와 퇴장 후 지연 쓰기는
[기존 완료·검증 근거](../planning/COMPLETED_TASKS.md)의 자동 검증 기록을 따른다.
아래는 실제 Firebase 연결 시간과 여러 기기의 화면 이동만 확인하는 마지막 세 시나리오다.

**2026-08-31 실행 결과: 세 시나리오 모두 통과(사용자 명시 확인).**
테스트 환경은 라이어스포커 / Android Medium Tablet 에뮬레이터 + 실제 휴대폰 A32·A35다.
아래 메모는 사용자가 남긴 성공 확인과 출시 후 개선 의견을 함께 보존한다.
메모가 있다는 이유로 실패로 처리하지 않는다. 물리 태블릿·iOS·다른 게임의 통과로
확대하지 않으며, 기존 반복 단절·타이머·퇴장 잔류·종료 복귀 항목은 보고 환경에서 통과다.

**기록 방식:** 실행한 항목에 이상이 없으면 아래 메모를 비워 둔다. 실행한 전체 항목의 빈
메모는 통과로 처리한다. 하지 못한 항목만 메모에 `미실행: 이유`를 쓴다.
오류가 있을 때만 `직전 조작 / 기기 역할 / 걸린 시간 / 화면 문구`를 적는다.
모르는 시각·문구는 추정하지 않는다. 이메일·UID·token이 보이는 화면은 공유하지 않는다.

## 1. 같은 게임에서 휴대폰 두 번 단절 → 복구 → 종료

1. 휴대폰 A의 차례에 비행기 모드를 켠다. 30초 안에 태블릿에서 A의 `연결 끊김`과
   게임 중단 화면이 나타나야 한다. 30초가 넘어도 없으면 그 시도는 실패로 메모한다.
2. **태블릿 중단 화면이 나타난 시점부터 5초 더 기다렸다가** A의 비행기 모드를 끈다.
   30초 안에 같은 방·게임으로 복귀하고 B는 계속 남아 있어야 한다. 타이머는 서버가
   멈춘 남은 시간부터 재개하며, 기다린 5초가 차감되거나 처음부터 초기화되면 실패다.
   휴대폰 로컬 네트워크 팝업이 먼저 뜬 시간은 서버 중단 시작으로 계산하지 않는다.
3. **새 게임을 시작하지 않고 같은 게임에서** A의 차례에 1~2를 한 번 더 반복한다.
   두 번째에도 A·B가 로비로 튕기지 않고 태블릿에서 게임 조작이 가능해야 한다.
4. 태블릿에서 게임을 종료하고 `홈으로 나가기`를 누른다.
   A·B 모두 앱 재실행 없이 그룹 대기실로 돌아와야 한다. 검정 화면은 실패다.

메모(오류가 있을 때만; 타이머 문제면 중단 직전 / 복구 직후 숫자도 기록):

**통과.** 사용자는 태블릿 중단 화면 뒤 30초를 기다렸다가 네트워크를 복구했고 6초가
남아 있었다고 보고했다. 서버가 멈춘 남은 시간부터 재개한 것 같으며 동작한다고 확인했다.
반복해서 네트워크를 끊고 복구해도 문제없이 게임이 진행됐다. 이 시나리오 전체 통과이며
문제가 있어서 메모한 것이 아니라고 명시했다. 사용자가 이 시간 재개 방식을 납득할지에
대한 의견만 [출시 후 개선](../planning/TASKS.md#game-pause-ux-01--단절-후-남은-시간-재개-안내)으로 기록한다.

## 2. 태블릿 단절 복구와 퇴장 참가자 잔류

1. 새 게임에서 휴대폰 인터넷은 유지하고 태블릿만 25초 이상 끊었다가 복구한다.
   30초 안에 같은 게임으로 돌아오고 재연결 안내가 사라지며 조작이 가능해야 한다.
2. 태블릿을 다시 끊고 휴대폰 A에서 `게임과 그룹 나가기`를 선택한다.
   A가 홈으로 나가는지 확인한 뒤 태블릿을 복구한다.
3. 태블릿에서 게임 종료·대기실 복귀를 마친다. 인원 부족으로 게임이 끝나도 정상이다.
   A는 명단에 다시 나타나면 안 되고, 남은 B는 검정 화면 없이 그룹으로 돌아와야 한다.
   다음 시나리오 전 A는 직접 다시 참가한다.

메모(오류가 있을 때만): **테스트 항목 모두 통과.**

## 3. winner 직후 태블릿 강제 종료·재시작

1. 새 게임을 정상 종료해 휴대폰에 winner 화면이 나오게 한다.
2. 태블릿에서 `홈으로 나가기`를 누르기 **전에** 태블릿 앱을 강제 종료하고 다시 연다.
3. 태블릿은 그룹 대기실로 돌아오고 A·B의 winner 화면도 닫혀야 한다.
   이전 finished 화면·검정 화면이 없고, 태블릿에서 다음 게임을 선택할 수 있어야 한다.

메모(오류가 있을 때만):

**통과.** 태블릿을 강제 종료했을 때 winner 표시 화면 밑에 `태블릿 오류 화면`이 뜬다고
보고했다. 사용자는 이를 오류가 아닌 추후 수정 사안으로 지정했다.
[winner 아래 연결 안내 겹침](../planning/TASKS.md#winner-connection-layer-01--winner-아래-태블릿-연결-안내-겹침)으로
기록하며 winner 종료·대기실 복귀의 통과 판정은 유지한다.
