# 진입 연출 테이블·의자 이미지 만들기

게임 진입 연출(`PlayerLayoutEditor`)은 자리 배치가 끝나면 테이블과 의자를 화면에
깔았다가, 테이블로 줌인해 그대로 게임 화면으로 이어집니다. 그래서 테이블 상판과
의자 앉는 면은 **그 게임의 `background.png`와 같은 재질·색**이어야 합니다. 다르면
줌인이 끝나는 순간 화면이 바뀐 느낌이 납니다.

`tool/fill_layout_asset.py`가 가운데가 빈 템플릿을 받아 그 면을 게임 배경으로
채우고 에셋 경로에 저장합니다.

---

## 그대로 복사해 쓰는 프롬프트

템플릿 PNG를 아무 데나 저장해 두고, 아래를 채워서 보내세요.

```
진입 연출용 테이블·의자 이미지를 만들어줘.

- 게임: <게임 폴더 이름 (예: final_call)>
- 테이블 템플릿: <경로 (예: ~/Desktop/layout_table.png)>
- 의자 템플릿: <경로 (예: ~/Desktop/layout_chair.png)>

tool/fill_layout_asset.py로 두 장 다 처리하고,
저장 전에 --preview로 배경 위에 얹은 그림을 보여줘.
채운 면이 배경과 이음매 없이 붙는지 확인한 다음 저장해줘.
```

한 장만 필요하면 해당 줄만 남기면 됩니다. 밝기가 마음에 안 들면 이어서
"조금 더 어둡게" 라고만 해도 `--darken`을 조정해 다시 돌립니다.

---

## 템플릿 준비 조건

- **가운데를 완전히 투명(알파 0)하게** 비워둘 것. 흰색으로 칠하면 안 됩니다.
- **테두리 도형이 닫혀 있을 것.** 비운 가운데가 바깥 여백과 이어져 있으면 안쪽과
  바깥을 구분할 수 없어 도구가 오류를 냅니다.
- 정사각형 PNG 권장. 기존 에셋은 1254×1254 입니다.
- 파일 이름은 자유입니다. 저장될 이름은 `--kind`가 정합니다.

## 직접 실행하기

```bash
python3 tool/fill_layout_asset.py --game final_call --kind table --template ~/Desktop/layout_table.png
```

| 옵션 | 설명 |
| --- | --- |
| `--game` | `assets/games/` 아래 폴더 이름 |
| `--kind` | `table` 또는 `chair`. 저장 이름과 기본값을 결정합니다 |
| `--template` | 가운데가 투명한 PNG 경로 |
| `--texture` | 채울 재질. 기본값은 그 게임의 `background.png` |
| `--out` | 저장 경로. 기본값은 `assets/games/<game>/images/layout/layout_<kind>.png` |
| `--darken` | 배경 대비 밝기 배율 |
| `--shadow-width` / `--shadow-strength` | 앉는 면 안쪽 그림자 |
| `--preview` | 배경 위에 얹은 확인용 이미지 저장 |
| `--dry-run` | 저장하지 않고 숫자만 보고 |

## 기본값의 근거

이미 손으로 만들어 둔 라이어스포커·파이널콜 에셋에서 가장자리 거리별 밝기를 재고,
파라미터를 훑어 오차가 가장 작은 값을 골랐습니다(픽셀 평균 오차 255 중 2.8~6.6).

| | 측정 결과 | 기본값 |
| --- | --- | --- |
| 테이블 | 안쪽이 거의 균일(54.2 → 52.0). 그림자 없음 | 밝기 0.94 |
| 의자 | 팔걸이 안쪽으로 그림자(40.8 → 55.4) | 밝기 0.95, 폭 0.04, 세기 0.12 |

밝기는 게임 아트에 따라 갈립니다(테이블 기준 라이어스포커 0.90, 파이널콜 0.98).
한 값으로 두 게임을 다 맞출 수 없으므로, 실행하면 찍히는 `배경 대비 밝기`를 보고
`--darken`으로 한 번 더 돌리는 것을 전제로 합니다.

## 새 게임을 추가할 때

`pubspec.yaml`의 `assets:`에 `assets/games/<game>/images/layout/`을 추가해야 합니다.
빠뜨리면 빌드는 되지만 연출에서 이미지가 뜨지 않습니다.
