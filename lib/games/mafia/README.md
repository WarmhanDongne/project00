# 마피아 게임 설계 결정 기록

> 화면 디자인은 **사용자가 직접 제작해 전달**합니다. 이 문서는 어떤 화면이
> 필요하고 각 화면에 어떤 기능이 들어가야 하는지의 기능 명세만 기록합니다.
> AI는 화면을 임의로 디자인하지 않습니다.

## 확정된 규칙 (인터뷰 결과)

| 항목 | 결정 |
|---|---|
| 최대 인원 | **12명** (플랫폼 상한 6→12 확장 필요 — 아래 참고) |
| 밤 진행 | 특수직 **동시 진행**. 전원 완료되면 아침 |
| 밤의 시민 휴대폰 | **아무것도 표시하지 않음** (밤 배경만) |
| 마피아 다수 지목 | **다수결**, 동표면 **랜덤** |
| 낮 투표 | **비밀 투표(휴대폰) + 태블릿 개표**, 동표면 무처형 |
| 처형자 신분 | **공개** |
| 사망자 화면 | **전원 신분 열람** + "다른 사람에게 보여주지 마세요" 문구 |
| 낮 토론 | **자유 토론 + 전체 타이머** (길이 미정) |

## 필요한 화면 목록 (사용자 제작 대상)

### 휴대폰
1. **역할 카드 확인** — role_back 뒤집기(기존 연출 재활용). 신분별 카드 앞면
2. **밤 — 신분별 행동** (신분별 기본 템플릿은 사용자가 전달 예정)
   - 마피아: 생존자 지목 + 동료 마피아의 현재 선택 실시간 표시
   - (의사·경찰 확정 시) 의사: 보호 대상 선택 / 경찰: 조사 대상 선택 + 결과 표시
3. **밤 — 시민** — 밤 배경만, 조작 없음
4. **낮 투표** — 생존자 목록에서 1명 비밀 지목
5. **사망 후** — dead_message → 전원 신분 열람(+공개 금지 문구), 게임 끝까지 관전
6. **결과** — 마피아 승/시민 승
7. (미정) 아침 발표~토론 동안 휴대폰에 무엇을 보여줄지

### 태블릿
1. **역할 배분 연출**
2. **밤** — background_night + 새(bird) 애니메이션, 진행 상황 표시(누가 완료했는지는 비공개)
3. **아침 발표** — 사망자 공개 또는 "아무도 죽지 않았습니다"
4. **낮 토론** — 전체 타이머
5. **개표 연출** — vote_box 에셋
6. **처형 발표** — 처형자 + 신분 공개 / 동표면 무처형 안내
7. **결과**

### 제외하기로 한 것
- 채팅(오프라인 대화로 대체), 유언 작성, 사망자의 밤 행동 실시간 관전

## 미확정 (다음 대화에서 결정)

1. **역할 세트**: 마피아+시민만인지, 의사·경찰 포함인지. 추가 직업 여부
2. **인원별 역할 배분표** (4~12명: 인원별 마피아 수)
3. 경찰 조사 결과 표기: "마피아다/아니다"만?
4. 의사 규칙: 자기 자신 보호 허용? 같은 사람 연속 보호 허용?
5. 타이머 길이: 밤 행동 / 낮 토론 / 투표 + **밤 미조작 타임아웃 처리**(랜덤? 스킵?)
6. 승리 조건 확인: 마피아 전멸=시민 승, 생존 마피아 수 ≥ 생존 시민 수=마피아 승?
7. 첫날은 밤부터 시작? 낮부터 시작?
