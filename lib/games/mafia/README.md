# 마피아 게임 설계 결정 기록

> 화면 디자인은 **사용자가 직접 제작해 전달**합니다. 이 문서는 어떤 화면이
> 필요하고 각 화면에 어떤 기능이 들어가야 하는지의 기능 명세만 기록합니다.
> AI는 화면을 임의로 디자인하지 않습니다.
> 인원수별 신분 규칙(역할 배분표)은 사용자가 별도로 정리해 전달합니다.

## 확정된 규칙 (인터뷰 결과)

| 항목 | 결정 |
|---|---|
| 최대 인원 | **12명** (플랫폼 상한 6→12 확장 필요 — 아래 참고) |
| 밤 진행 | 특수직 **동시 진행**. 전원 완료되면 아침 |
| 밤의 시민 휴대폰 | **아무것도 표시하지 않음** (밤 배경만) |
| 마피아 다수 지목 | **다수결**, 동표면 **랜덤** |
| 낮 투표 | **비밀 투표(휴대폰) + 태블릿 개표**, 동표면 무처형 |
| 처형자 신분 | **공개** |
| 사망자 화면 | **전원 신분 열람** + "다른 사람에게 보여주지 마세요" 문구 |
| 낮 토론 | **자유 토론 + 전체 타이머** (길이 미정) |
| 신분 규칙 | 인원수별 배분표는 **사용자가 별도 전달** |

## 게임 흐름 (서버 phase 초안)

```
roleReveal(역할 확인) → night(밤) → morning(아침 발표) → [승패 판정]
→ day(토론) → voting(투표) → voteResult(개표·처형 발표) → [승패 판정]
→ night → … → finished
```

- 승패 판정 시점 2곳: 아침 발표 직후, 처형 발표 직후
- (가정) 첫날은 역할 확인 직후 **밤부터** 시작 — 확인 필요
- 태블릿 연출 완료는 기존 패턴대로 `game_mafia_complete_*` 명령으로 서버에 알림

## 휴대폰 화면 명세 (사용자 제작 대상)

모든 화면 공통: 상단바(팁/룰 · 설정 · 나가기), 나가기는 `leaveFunctionName`
경유, 중단(interruption) 레이어, 재접속 시 현재 phase 화면으로 복원.

### P1. 역할 카드 확인 — phase: roleReveal
- 표시: 뒷면 카드(role_back) → 탭하면 뒤집혀 내 역할 카드
  (`role_card_reveal_animation.dart` 재활용)
- 마피아일 때: **동료 마피아 명단 함께 표시** (가정 — 밤 화면에서만 볼지 확인)
- 조작: 카드 탭(공개) → 확인 버튼 → 서버에 확인 전달
- 이탈: 전원 확인 완료 시 서버가 night로 전환
- 재접속: 이미 확인한 상태면 뒤집힌 카드로 복원

### P2. 밤 — 마피아 지목 — phase: night, 역할: 마피아
- 표시: 밤 배경, 생존자 목록(동료 마피아 제외), **동료 마피아의 현재 선택
  실시간 표시**, 남은 시간
- 조작: 대상 탭 = 선택(마감 전 변경 가능)
- 확정: 타이머 종료 또는 마피아 전원 선택 완료 → 서버가 다수결(동표 랜덤)
- 완료 후: P5(빈 밤 화면)와 같은 모습으로 전환

### P3. 밤 — 의사 (역할 세트에 포함될 경우)
- 표시: 밤 배경, 생존자 목록, 남은 시간
- 조작: 보호 대상 1명 선택 (자기 자신 허용 여부 = 신분 규칙 대기)
- 완료 후: P5와 같은 모습으로 전환

### P4. 밤 — 경찰 (역할 세트에 포함될 경우)
- 표시: 밤 배경, 생존자 목록(자신 제외), 남은 시간
- 조작: 조사 대상 1명 선택 → **결과 즉시 표시**(표기 문구 = 신분 규칙 대기)
- 결과는 이 화면에서만 표시하고 서버 `private/{uid}`에 조사 기록 누적
- 완료 후: P5와 같은 모습으로 전환

### P5. 밤 — 시민·완료된 특수직 ✔ 확정
- 밤 배경만. 조작 없음. 문구 없음(특수직과 구분되지 않게)

### P6. 아침 발표 ~ 낮 토론 — phase: morning, day
- (가정 — 확인 필요) 낮 배경 + 생존/사망 현황 + 토론 남은 시간 표시.
  발표 연출 자체는 태블릿이 담당
- 내가 밤에 사망했다면 이 시점에 P9로 전환

### P7. 낮 투표 — phase: voting ✔ 방식 확정
- 표시: 생존자 목록(자신 제외 — 가정), 남은 시간
- 조작: 1명 지목 → 확정. (가정) 확정 후 변경 불가, 기권 없음,
  타임아웃 시 기권 처리
- 완료 후: "개표를 기다리는 중" 상태

### P8. 사망 후 (관전) ✔ 확정
- 진입 연출: dead_message
- **전원 신분 열람** + "다른 사람에게 보여주지 마세요" 문구
- 이후 게임 끝까지 관전(진행 상태 표시), 신분표는 버튼으로 재열람(가정)
- 나가기 가능

### P9. 결과 — phase: finished
- 승리 팀(마피아/시민) + 전원 신분 공개
- 재시작은 태블릿에서. 홈 이동 시 즉시 화면 전환(정리 장면 노출 금지)

## 태블릿 화면 명세 (사용자 제작 대상)

공통: 가로 고정 + 전체화면, 사이드바, 설정(재시작/종료), 룰북, 중단 레이어,
BGM(게임 시작 시 start / dispose에서 stop), 종료·홈은 즉시 화면 닫기.

### T1. 역할 배분 연출 — phase: roleReveal
- 카드가 각 좌석으로 배분되는 연출(공용 분배 애니메이션 응용 가능)
- 확인 완료 현황 표시 (n/m)

### T2. 밤 — phase: night ✔ 배경·연출 에셋 준비됨
- background_night + 새(bird) 4프레임 애니메이션
- "밤이 되었습니다" 안내. **개별 완료 여부는 표시하지 않음**(신분 유추 방지)

### T3. 아침 발표 — phase: morning
- 사망자 발표(프로필 + 사망 연출) 또는 "아무도 죽지 않았습니다"
- 의사가 살렸을 때 "의사가 살려냈습니다" 문구 여부 = 신분 규칙 대기
- 발표 연출 완료 → 서버에 완료 신호 → day 전환

### T4. 낮 토론 — phase: day ✔ 방식 확정
- 낮 배경, 좌석 배치(생존/사망 구분 표시), **전체 토론 타이머**
- 타이머 종료 → 서버가 voting 전환

### T5. 투표 진행 — phase: voting
- 투표 완료 인원 수 표시 (가정: 누가 했는지는 비공개, 인원수만)
- 전원 완료 또는 타임아웃 → 개표

### T6. 개표 연출 ✔ vote_box 에셋 준비됨
- 투표함에서 표가 나오는 연출, 득표 집계 표시

### T7. 처형 발표 ✔ 신분 공개 확정
- 최다 득표자 발표 + 신분 공개 / 동표면 "무처형" 안내
- 발표 완료 → 승패 판정 → 밤 또는 결과

### T8. 결과 — phase: finished
- 승리 팀 발표 + 전원 신분 공개
- 재시작 / 홈 버튼 (홈 = 서버 end 성공 후 즉시 닫기)

### 분기 규칙 — 역할 이름으로 분기하지 마세요

화면·서버는 `id == 'mafia'` 같은 이름 비교를 하지 않습니다. 아래 축으로만
분기하면 새 역할이 자동 동작합니다:

- `nightAction` — 밤에 무엇을 하는가(12종). 대상 선택 UI를 이 값으로 결정
- `nightPhase` — 언제 해결하는가(명세 2~9단계). 서버 처리 순서
- `faction` — citizen / mafia / **neutral**
- `abilityTiming` — none / night / day / gameStart / onDeath / passive
- `winCondition` — 진영 승리 또는 개별 조건(광대·처형자·생존자·최후생존·세력장악)

### 역할 추가가 서버 수정 없이 되는 이유

밤 해결 엔진이 역할 이름을 보지 않고 `nightAction`·`nightPhase`만 봅니다.
그래서 **경호원과 마피아 보스를 코드 한 줄 없이 켰습니다.**

- 경호원 = 의사와 같은 `protect`
- 마피아 보스 = 마피아와 같은 `eliminate` + `investigationAppearance: asCitizen`

덕분에 **10~12인 구성이 열렸습니다.** ⚠️ 단 경호원은 지금 "두 번째 의사"로
동작합니다. 고전 규칙(대상 대신 죽음)이 필요하면 데이터에 표시를 추가해야 합니다.

### Dart ↔ TypeScript 표 대조

역할 규칙이 Dart(화면)와 TS(서버) 두 곳에 있습니다. 갈리면 규칙이 **조용히**
깨지므로 `functions/test/mafia-role-parity.test.mjs`가 Dart 파일을 직접 파싱해
진영·밤 행동·해결 단계·조사 모습·동료 인지·구현 여부·구성표를 전부 대조합니다.
한쪽만 고치면 테스트가 먼저 실패합니다.

### `turnDeadlineAt` 이름을 쓰는 이유

마피아는 턴제가 아니라 단계제지만 마감 시각 필드 이름을 `turnDeadlineAt`으로
두었습니다. 공용 중단 모듈이 **이 이름을 찾아** 연결이 끊긴 동안 타이머를 멈추고
복귀 시 남은 시간을 되돌려 줍니다. 이름을 바꾸면 그 기능이 조용히 멈춥니다.

## 태블릿 처형 발표 3박자 (시안 확정 — 2026-08-20)

휴대폰과 **같은 3박자**입니다. 태블릿은 문구가 크고 카드가 화면 중앙에 옵니다.

| 박자 | 노드 | 내용 |
|---|---|---|
| 1 | `482:305` | `탈락자 닉네임` 64px Bold 검정, 해 중앙 |
| 2 | `1017:555` | 뒷면 카드 + 대상의 원형 사진 |
| 3 | `1017:566` | 앞면 카드 + `○○님은 시민이었습니다.` |

### 좌표 (가로 1194 × 834로 변환 완료)

세 프레임이 공유하는 것:

| 요소 | 위치 | 크기 |
|---|---|---|
| 종이 배경 | (0, −6) | 1199 × 899 |
| `sun` | (196, 18) | 802 × 802 (중심 597, 419) |
| 설정(기어) 아이콘 | (1048, 18) | 123 × 123 |
| 룰북(책) 아이콘 | (886, 31) | 149 × 98 |

박자별 차이:

| 요소 | 박자 2 | 박자 3 |
|---|---|---|
| 카드 | (454, **209**) 286 × 419.39 | (454, **178**) 286 × 419 |
| 원형 사진 | (539, 356) 116 × 116 | 없음 |
| 문구 | 없음 | (469, 627) 256 × 29, 24px Bold |
| 박자 1 문구 | `탈락자 닉네임` (412, 378) 369 × 77, 64px Bold, 중앙 597 |

**카드가 박자 2 → 3에서 31px 올라갑니다.** 실수가 아니라 필요한 이동입니다.
박자 2 위치(209)에 두면 카드 아래끝이 628이 되어 문구(627)와 겹칩니다. 그래서
**뒤집기와 함께 209 → 178로 올라가게** 배선합니다. 그러면 시안 두 장을 다
지키면서 카드가 튀지 않습니다.

원형 사진 중심(597, 414)은 카드 중심(597, 418.7)보다 4.7px 위입니다. 휴대폰
시안도 같은 값이라 그대로 씁니다.

### 회전 좌표 변환 규칙 (이 시안으로 직접 검증)

태블릿 프레임의 자식은 모두 −90° 회전 상태로 적혀 있습니다.

```
가로_left = 1194 − (감싼_div_top + 감싼_div_height)
가로_top  = 감싼_div_left
크기      = 안쪽 자식의 w × h (교환하지 않음)
```

해·카드·책 아이콘 3개 지점으로 확인했습니다. Flutter에서는 **회전하지 않고
똑바로** 배치합니다.

### 파일 위치 규칙 (2026-08-20 사용자 재정리)

| 종류 | 위치 |
|---|---|
| 게임 전용 효과음 | `assets/games/<게임>/sounds/` |
| 게임 전용 **배경음악** | `assets/games/<게임>/sounds/background/` |
| 여러 게임 공용 효과음 | `assets/sounds/` (평평하게) |

`assets/sounds/common/`은 없어지고 `assets/sounds/`로 평평해졌습니다
(dealing · lever · roulette · stamp).

**배경음악이 게임별로 갈라졌습니다.** 그래서 `AppSounds.background`를 없애고
각 게임의 `sound/<게임>_sounds.dart`에 두었습니다. `GameBackgroundMusic.start()`가
곡을 **인자로 받습니다**.

```dart
_bgm.start(MafiaSounds.background);      // 낮
_bgm.stop();
_bgm.start(MafiaSounds.nightBackground); // 밤 — 곡을 갈아 끼울 때
```

⚠️ **같은 5.4MB 배경음악 파일이 세 게임에 각각 복사돼 총 16MB입니다.**
라이어스포커에는 파일이 없어 BGM이 끊기던 것을 같은 파일로 채웠습니다. 세 게임이
같은 곡을 쓸 거라면 `assets/sounds/background.mp3` 하나로 되돌리는 편이 앱 용량에
훨씬 낫습니다. 게임마다 다른 곡을 쓸 계획이면 지금 구조가 맞습니다.

### 기자·탐정 능력 (확정 2026-08-20)

| 역할 | 능력 | 구현 |
|---|---|---|
| 기자 | 밤에 지목한 사람의 신분을 **아침에 전체 공개** | 새 행동 `expose`, 해결 단계 `statusEffect`(9) |
| 탐정 | 대상이 **누구에게 능력을 썼는지** 조사 | 기존 행동 `track`, 해결 단계 `investigate`(6) |

**기자는 경찰과 다릅니다.** 경찰 결과는 본인만 보므로 `private`에, 기자 결과는
모두가 보므로 `public.revealedRoles`에 씁니다. 그래서 **살아 있는 사람의 신분이
public에 들어오는 유일한 정상 경로**입니다.

**탐정은 카탈로그의 `추적자`와 같은 역할입니다.** 능력이 완전히 같아 새 역할을
만들지 않고 `displayName`만 시안 카드에 맞춰 `탐정`으로 바꿨습니다. id는
`tracker` 그대로입니다. 결과 문구는 대상이 고른 사람의 **닉네임**이고, 아무
행동도 안 했으면 `방문 없음`입니다(결과 화면이 36px 한 줄이라 짧게 담습니다).

두 역할 모두 **아직 인원별 구성표에 없어 실제로는 배분되지 않습니다.** 구성표에
넣으면 그때부터 나옵니다.
